  1. GitHub पर जाएं: github.com खोलें और अपना फ्री अकाउंट लॉगिन करें।
  2. New Repository बनाएं: ऊपर दाएँ कोने में + आइकन दबाकर New repository चुनें। Repository का नाम दें (जैसे: royal-coaching-fee) और इसे Public रखें।
  3. index.html फाइल अपलोड करें: uploading an existing file पर क्लिक करें और इस index.html फाइल को ड्रैग करके अपलोड करें, फिर Commit changes पर क्लिक करें।
  4. Pages Enable करें: उस Repository की Settings ➔ बाएँ मेनू में Pages ➔ Branch में main (या master) सेलेक्ट करके Save दबाएं।
  5. वेबसाइट लाइव: 1 मिनट में आपकी वेबसाइट का फ्री लिंक तैयार हो जाएगा: https://yourusername.github.io/royal-coaching-fee/
  6. फोन में Install करें: फोन के Chrome ब्राउज़र में यह लिंक खोलें, ऊपर 3 डॉट्स दबाएं और "Add to Home screen" पर क्लिक करें। ऐप जैसा आइकन आपके फोन पर आ जाएगा!
